# نحو ميسّر

تطبيق أندرويد (Kotlin + Jetpack Compose) لتبسيط تعلّم النحو العربي، موجّه لمتعلمي القرآن والعامة.
يعمل دون إنترنت، وواجهته عربية من اليمين إلى اليسار.

## المحتوى الحالي (12 درساً، 72 سؤالاً)
أقسام الكلام ← أنواع الفعل ← الجملة الاسمية والفعلية ← المبتدأ والخبر ← الفاعل ← المفعول به ← حروف الجر ← المضاف والمضاف إليه ← النعت ← كان وأخواتها ← إنَّ وأخواتها ← علامات الإعراب الفرعية (المثنى والجمع السالم)

كل درس: شرح قصير + أمثلة (بعضها قرآني مع الإعراب) + تدريب اختيار من متعدد مع تفسير فوري.
يُحفظ التقدم وأفضل نتيجة والأيام المتواصلة على الجهاز.

**مراجعة أخطائي:** كل سؤال يُجاب عنه خطأً يُسجَّل تلقائياً، وتظهر في الشاشة الرئيسية بطاقة لمراجعتها.
يُحذف السؤال من القائمة عند الإجابة عنه صحيحاً (في المراجعة أو في تدريب الدرس نفسه).
يُحدَّد السؤال بنص صياغته، لذا إن عدّلت نص سؤال في `content.json` فسيُعدّ سؤالاً جديداً.

## التشغيل
1. افتح المجلد في **Android Studio** (Koala أو أحدث) وانتظر مزامنة Gradle.
2. شغّل على هاتفك أو المحاكي (Run).
3. لملف APK: Build ← Build APK(s).

## إضافة دروس وأسئلة
كل المحتوى في ملف واحد: `app/src/main/assets/content.json`.
انسخ أي درس في الملف وغيّر نصوصه، مع الانتباه إلى:
- `id` فريد لكل درس.
- `answer` رقم الإجابة الصحيحة في `options` بدءاً من 0.
- حتى 4 خيارات لكل سؤال.
لا حاجة لتعديل أي كود.

## تنبيهات قبل النشر
- **راجع المحتوى النحوي مع مختص** قبل نشره، خصوصاً الأمثلة القرآنية وإعرابها.
- اكتب دروسك وأسئلتك بنفسك ولا تنسخ من الكتب المدرسية أو المواقع (حقوق النشر).
- للنشر في Google Play ستحتاج سياسة خصوصية، خصوصاً عند إضافة الإعلانات.
